# The Memory Tune-Up — your task

You've taken over this messy project. Use **Claude Code** to do these five things — one per video in the module. You don't do any of it by hand; you tell Claude what you want and check its work.

Submit what Claude produced for each, plus one line on what you asked.

---

### 1. Weekly review  · *(Weekly Maintenance)*
Ask Claude to review `CLAUDE.md`, `memory.md` and `tasks.md`: flag anything no longer true, close finished tasks, and show you what to cut. Then apply the changes.
**Submit:** the list of stale/finished items it found + what you changed.
*Good looks like:* it catches the contradictions (e.g. the day the data arrives) and the tasks that are already done.

### 2. Save, then start fresh  · *(Fresh Sessions)*
Before you open a brand-new session, ask Claude to save the key decisions and lessons from your work so far into a notes file. Then start a fresh session.
**Submit:** the saved notes file.
*Good looks like:* the important stuff is written down *before* you reset — so nothing is lost.

### 3. Split the memory  · *(Lazy Loading)*
`memory.md` is one long jumbled file. Ask Claude to split it into a short **index** plus one file per topic (decisions · lessons · data), and load only the index by default.
**Submit:** the `memory-index` file + the topic files.
*Good looks like:* a one-page index that names each file; the details live in separate files opened only when needed.

### 4. Write a skill file  · *(The Skill File)*
Pick the task the team repeats every week — "clean & summarise the dataset." Ask Claude to turn it into a skill file with a **name · when to use it · steps · one example.**
**Submit:** the skill file.
*Good looks like:* all four parts present, scoped to that one job.

### 5. Skill or agent?  · *(Skills vs. Agents)*
Look at the three repeated tasks in the `README`. Sort each as a **skill** or an **agent**, with one line of why. Then ask Claude to build **one** of them.
**Submit:** your sort + the thing you built.
*Good looks like:* "clean the dataset" and "build the chart" = skills; "produce the full report pack, deciding as it goes" = an agent.
