# Memory index

Load this file by default. Open a topic file only when the task actually needs it.

- [`memory/decisions.md`](memory/decisions.md) — why we do things the way we do (house format, Monday shipping, drop-empty-rows, recompute totals). Open when questioning or changing a convention in `CLAUDE.md`.
- [`memory/lessons.md`](memory/lessons.md) — past incidents and the fixes they led to (March totals bug, April outlier miss, stale-chart mistake). Open before shipping a report, to avoid repeating a known mistake.
- [`memory/data.md`](memory/data.md) — where the raw data and template live, and column quirks. Open when touching `data/*.csv` or the report template.
